A context builds its map the first time it needs it. Each model becomes a table, columns, a key, indexes, foreign keys, and relations. Three layers contribute, and a later layer wins: conventions, then attributes, then the fluent mapper in `map()`.

You do not write Tyhp to use this. `model`, `belongsTo`, `hasOne`, `hasMany`, `belongsToMany`, `using`, and `extraColumn` take the type first, as in [Getting started](rhetoric_php_getting_started.md). Property paths are `\Tyhp\Expression::of(Post::class)->slug`.

`php artisan rhetoric:show "App\Data\ChirpContext"` prints the map. On PHP 8.3, attributes placed on a hooked property are not read; set that fact in `map()` instead.

## Conventions

| Source | Result |
| --- | --- |
| Class `Chirp` | table `chirps` |
| Property `userId` | column `user_id` |
| `int $id` | primary key, generated by the database |
| A property typed as another model, plus `{property}Id` on this class | belongs-to |
| A property whose `#[\Tyhp\PropertyType('array<App\\Data\\Post>')]` names another model, and that model has `{thisModel}Id` (`blogId` for `Blog`) | has-many |
| The same array property when neither side has that foreign key | belongs-to-many. The pivot table is the two snake_case class names, sorted, joined with `_` |

A bare `array` type names no model, so a collection relation needs the `#[\Tyhp\PropertyType]` attribute, including when you declare it with `hasMany` or `belongsToMany` in `map()`.

`DateTimeImmutable` uses the built-in date cast. `bool` is stored as an integer. Backed enums use the built-in enum cast.

## Attributes

These classes live in `Tyhp\Rhetoric\Attributes`. Put them on the class or the property they describe.

On the class: `#[Table('users')]`, `#[Timestamps]` (`created_at` / `updated_at`), `#[SoftDeletes]` (`deleted_at`), `#[Keyless]`, `#[ObservedBy(PostObserver::class)]`, `#[Discriminator('kind')]`, `#[DiscriminatorValue('cat')]`. `#[Index]` is repeatable and lists property names:

```php
#[\Tyhp\Rhetoric\Attributes\Index(properties: ['slug'], unique: true)]
class Post
{
}
```

On a property: `#[Column('blog_id')]`, `#[MaxLength(255)]`, `#[Precision(12, 2)]`, `#[Text]`, `#[DefaultValue(0)]`, `#[Generated]`, `#[Comment('...')]`, `#[Key]` (repeat it for a composite key), `#[NotMapped]`, `#[Cast(MoneyCast::class)]`, `#[AsJson]`, `#[Embedded]`, `#[Deferred]`, `#[ConcurrencyCheck]`, `#[RowVersion]`, `#[ForeignKey(Blog::class)]`. `ForeignKey` accepts a referenced column and an `Tyhp\Rhetoric\OnDelete` value: `Cascade`, `SetNull`, or `Restrict`. `#[InverseOf]` names the property on the other model; its constructor takes that property name as a string when you are not using Tyhp's `nameof`.

## Fluent mapper

Override `map` on the context. `model` takes the model class:

```php
protected function map(\Tyhp\Rhetoric\Mapping\Mapper $map): void
{
    $posts = $map->model(\App\Data\Post::class)();
    $posts->table('posts')
        ->hasIndex(\Tyhp\Expression::of(\App\Data\Post::class)->slug)
        ->unique();
    $posts->column(\Tyhp\Expression::of(\App\Data\Post::class)->title)
        ->maxLength(200);
    $posts->belongsTo(\App\Data\Blog::class)(\Tyhp\Expression::of(\App\Data\Post::class)->blog)
        ->inverseOf(\Tyhp\Expression::of(\App\Data\Blog::class)->posts)
        ->foreignKey(\Tyhp\Expression::of(\App\Data\Post::class)->blogId)
        ->onDelete(\Tyhp\Rhetoric\OnDelete::Cascade);

    $blogs = $map->model(\App\Data\Blog::class)();
    $blogs->hasMany(\App\Data\Post::class)(\Tyhp\Expression::of(\App\Data\Blog::class)->posts);

    $posts->belongsToMany(\App\Data\Tag::class)(\Tyhp\Expression::of(\App\Data\Post::class)->tags)
        ->pivotTable('post_tag')
        ->pivotColumns('post_id', 'tag_id');
    $posts->belongsToMany(\App\Data\Tag::class)(\Tyhp\Expression::of(\App\Data\Post::class)->tags)
        ->using(\App\Data\PostTag::class)();

    $posts->addGlobalScope(
        \Tyhp\Expression::of(\App\Data\Post::class)->deletedAt->same(null),
    );
    $posts->softDeletes();
    $posts->observedBy(\App\Data\PostObserver::class);
    $posts->seed(['title' => 'Hello']);
}
```

`using` takes the pivot class, then no value arguments. `extraColumn(\Tyhp\Type::string)('legacy')` takes the value type, then the column name. `column`, `key`, `alternateKey`, `hasIndex`, `discriminator`, `inverseOf`, and `foreignKey` take the property path directly. Other `ModelMapper` methods: `comment`, `keyless`, `fromView`, `discriminatorValue`, and `addGlobalScope`. `ColumnMapper` methods: `name`, `maxLength`, `precision`, `generated`, `comment`, `type`, `text`, `default`, `cast`, `asJson`, `embedded`. `hasOne` is the single-object form of `hasMany` and takes the related class the same way.

`$map->conventions($conventions)` replaces table, column, and foreign-key naming. Subclass `\Tyhp\Rhetoric\Mapping\Conventions` and override `tableName`, `columnName`, `foreignKeyProperty`, `modelKeyProperty`, `pivotTable`, or `pivotForeignKey`.

`$map->intercept($interceptor)` registers a `\Tyhp\Rhetoric\Observers\QueryInterceptor`. Implement `beforeExecuting(string $sql, array $bindings, \Illuminate\Database\Connection $connection): void`.

## Casts

Extend `\Tyhp\Rhetoric\Casts\Cast` and implement `get` and `set`. `null` stays `null`. Built-in casts already cover `int`, `bool`, `\DateTimeImmutable`, and backed enums. A class-typed property with a cast is a column, not a relation.

```php
/**
 * @extends \Tyhp\Rhetoric\Casts\Cast<\App\Data\Money, int>
 */
final class MoneyCast extends \Tyhp\Rhetoric\Casts\Cast
{
    public function get(mixed $value): mixed
    {
        if ($value === null) {
            return null;
        }

        return new \App\Data\Money((int) $value);
    }

    public function set(mixed $value): mixed
    {
        if ($value === null) {
            return null;
        }
        if ($value instanceof \App\Data\Money) {
            return $value->cents;
        }

        throw new \InvalidArgumentException('Expected money.');
    }
}
```

## Inheritance, scopes, and observers

`#[Discriminator('kind')]` on the root and `#[DiscriminatorValue('cat')]` on each subclass share one table. A query for the root hydrates each row as its subclass. `addGlobalScope` adds a predicate to every query; `withoutGlobalScopes()` on a query skips them. `fromView('audit_posts')` and `keyless()` map a read-only model.

Subclass `\Tyhp\Rhetoric\Observers\Observer` and override any of `creating`, `created`, `updating`, `updated`, `saving`, `saved`, `deleting`, `deleted`, `restoring`, and `restored`. Attach it with `#[ObservedBy(PostObserver::class)]` or `observedBy`.
